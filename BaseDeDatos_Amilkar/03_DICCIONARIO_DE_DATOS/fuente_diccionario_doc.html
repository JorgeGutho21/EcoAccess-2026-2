Cómo leer este diccionario

Cada columna de las 19 tablas tiene una ficha propia con 24 puntos numerados, siempre en el mismo orden. Así, si el profesor pregunta por cualquier atributo, la respuesta se busca igual en todos los casos:

N.ºPunto de la fichaN.ºPunto de la ficha
1Nombre de la tabla (y qué guarda)13Quién lo consulta
2Nombre del atributo14Ejemplo de valor correcto
3Qué significa15Ejemplo de valor incorrecto (con el error ORA- que da Oracle)
4Para qué sirve16Qué problema evita
5Por qué existe17Qué pasaría si no existiera
6Tipo de dato y tamaño18Consultas, procedimientos y triggers que lo usan
7Si acepta NULL (y qué significa vacío)19Si se usa en C#
8Valor por defecto20Si se usa en Telegram
9Si es PK o FK (y sus CHECK / UNIQUE)21Si se usa en Power BI
10Con qué tabla se relaciona22Cómo podría preguntarlo el profesor
11Qué proceso del sistema lo usa23Una consulta SELECT para verlo
12Quién lo llena24Explicación sencilla, para quien está empezando

Los atributos que más suele preguntar el profesor (claves, estados, pesos, EcoPuntos, verificador, fechas y la marca de datos sintéticos) tienen además una Explicación ampliada escrita a mano.

Las fichas no se escribieron sobre un dibujo, sino que se generaron con generar_diccionario.ps1 a partir de cuatro fuentes verificables:

  • Los metadatos reales de Oracle (USER_TAB_COLUMNS y USER_CONSTRAINTS): tipo, tamaño, NULL, valor por defecto, PK, FK, UNIQUE, CHECK e IDENTITY.
  • La explicación humana de cada columna (fuente_diccionario.txt) y la explicación ampliada (fuente_explicacion_ampliada.txt).
  • El código del proyecto: las vistas, paquetes y triggers que nombran la columna, y las vistas VW_BI_* que la llevan a Power BI.
  • Oracle en ejecución: los 173 SELECT del punto 23 se ejecutaron contra la base el 11/11/2026 con 0 errores (16_EVIDENCIAS_Y_PRUEBAS/salidas/diccionario_173_select.txt).

Además, el instalador (INSTALAR_Y_PROBAR.ps1, comprobaciones D09 y D10) compara las 173 columnas documentadas con las 173 que existen en Oracle y verifica que todas tengan su COMMENT ON COLUMN.
