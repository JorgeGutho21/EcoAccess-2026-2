## 3. Si necesita TODOS los archivos

**Método sencillo (Windows):**

1. Desde el repositorio, cambie primero a la rama `entrega/base-de-datos-amilkar-2026`.
2. Pulse **Code → Download ZIP**.
3. Espere a que termine la descarga y abra **Descargas**.
4. Haga clic derecho en el ZIP → **Extraer todo**; elija una ruta corta, por ejemplo `C:\EcoAccess_Entrega`.
5. Dentro de la carpeta extraída, entre en `BaseDeDatos_Amilkar` y abra `00_EMPEZAR_AQUI\LEEME_PRIMERO.md` o `01_DOCUMENTO_FINAL\INFORME_FINAL_BASE_DE_DATOS_ECOACCESS.pdf`.

**Importante:** ese botón descarga **toda la rama del repositorio**, no únicamente la carpeta `BaseDeDatos_Amilkar`. Si solo necesita el material académico, puede conservar exclusivamente esa carpeta después de extraer. No hace falta ejecutar nada para leer los PDF.

**Para colaboradores con Git (opcional):** se puede clonar solo el directorio académico con sparse checkout:

```powershell
git clone --filter=blob:none --sparse --branch entrega/base-de-datos-amilkar-2026 https://github.com/JorgeGutho21/EcoAccess-2026-2.git
cd EcoAccess-2026-2
git sparse-checkout set BaseDeDatos_Amilkar
```

GitHub solicitará autenticación apropiada si la cuenta no está conectada. No pegue tokens ni credenciales en documentos o mensajes.

**Si recibió un ZIP independiente de la universidad**, ábralo y confirme que contiene `BaseDeDatos_Amilkar/00_EMPEZAR_AQUI`; verifique el manifiesto incluido. Los ZIP de entrega no se publican necesariamente dentro de GitHub.

## 5. Si desea ejecutar SQL: preparación segura

**Antes de hacer cualquier prueba**, lea el [manual de instalación](../11_GUIAS_PASO_A_PASO/MANUAL_INSTALACION_Y_RECUPERACION.pdf). Las siguientes conexiones corresponden a la **instalación local académica**, no a Oracle Cloud:

| Campo | Valor documentado |
|---|---|
| Host | `localhost` |
| Puerto | `1521` |
| Servicio | `FREEPDB1` |
| Proyecto | `ECOACCESS_BD` |
| Ejercicios | `ECOACCESS_PRACTICAS` |
| Power BI (lector) | `ECOACCESS_BD_LECTOR` |

Los usuarios deben existir previamente en su Oracle. Cada persona usa las contraseñas de **su propia instalación**; ninguna se publica en GitHub.

1. Abra SQL Developer.
2. Pulse el botón de nueva conexión (**+**).
3. Escriba un nombre descriptivo (por ejemplo `EcoAccess académico`), el usuario apropiado y su contraseña local.
4. Introduzca host `localhost`, puerto `1521` y servicio `FREEPDB1` (tipo **Nombre del servicio**, no SID).
5. Pulse **Probar**. Solo si el resultado es correcto, pulse **Conectar**.
6. Expanda **Tablas** o abra una **Hoja de trabajo SQL**. Para una comprobación de solo lectura ejecute:

```sql
SELECT USER AS usuario_actual,
       SYS_CONTEXT('USERENV','CON_NAME') AS contenedor
FROM dual;

SELECT table_name
FROM user_tables
ORDER BY table_name;
```

7. **Ctrl+Enter** ejecuta la sentencia seleccionada; **F5** ejecuta el script (múltiples sentencias e instrucciones de SQL*Plus). Lea los resultados en su panel correspondiente.

**No ejecute `99_reversion_esquema_academico.sql` ni `-Reinstalar` para estudiar**: pueden eliminar objetos del esquema académico. Tampoco ejecute scripts de instalación sobre P3, HR o la nube.

### Instalar o comprobar el esquema en su PC

En la carpeta `BaseDeDatos_Amilkar`, con Oracle local preparado y PowerShell 7:

```powershell
pwsh -File .\INSTALAR_Y_PROBAR.ps1
```

El modo normal revisa el esquema y ejecuta comprobaciones; para entender exactamente las operaciones y sus permisos, consulte el manual antes de utilizarlo. **No use `-Reinstalar`** salvo que tenga respaldo y autorización.
