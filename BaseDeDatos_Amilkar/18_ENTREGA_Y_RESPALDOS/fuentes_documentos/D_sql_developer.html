Antes de empezar: tres ideas que conviene tener claras

SQL Developer no es la base de datos. La base de datos es el programa Oracle AI Database 26ai Free, que funciona en segundo plano en el PC (como un servicio de Windows) aunque no haya ninguna ventana abierta. SQL Developer es solo una «ventanilla» para hablar con ella. C# y Power BI son otras ventanillas distintas. Las tres llegan al mismo lugar: el servicio FREEPDB1 que escucha en el puerto 1521 del propio equipo (localhost).

PiezaQué esAnalogía
Oracle Database 26ai FreeEl motor que guarda las tablas y ejecuta SQL y PL/SQL.El banco, con su bóveda.
Listener (puerto 1521)El programa que recibe las conexiones y las pasa a la base correcta.El portero del banco.
FREEPDB1La base «enchufable» (PDB) donde viven los esquemas del proyecto.La sucursal.
Esquema ECOACCESS_BDEl usuario dueño de las 19 tablas, 9 vistas, 4 paquetes, 5 programas sueltos y 4 triggers.La cuenta del proyecto dentro de la sucursal.
SQL Developer / C# / Power BIClientes que se conectan.Personas que van a la ventanilla.

Un esquema es un usuario. En Oracle, crear el usuario ECOACCESS_BD crea también un espacio con su nombre donde se guardan sus objetos. El proyecto usa tres:

UsuarioPara quéQué puede hacer
ECOACCESS_BDEl modelo ambiental (19 tablas).Dueño: crea, modifica y prueba sus objetos.
ECOACCESS_PRACTICASLos ejercicios de clase (precio final, salario, notas, HR, CRUD sin DELETE).Dueño de sus propias tablas de práctica; separado del modelo ambiental.
ECOACCESS_BD_LECTORPower BI y consultas de solo lectura.Solo SELECT sobre las vistas VW_BI_*. Si intenta leer la tabla USUARIO, Oracle responde ORA-00942 (prueba T03, 10/10).

Las contraseñas nunca se escriben en esta guía, en los scripts ni en Git. Viven solo en este PC, en _LOCAL_NO_PUBLICAR/credenciales_locales.env (carpeta excluida del ZIP). Cuando SQL Developer pida la contraseña, escríbela tú en el cuadro; no la pegues en ninguna hoja SQL que vayas a guardar.

Abrir SQL Developer

Dónde está instalado

En este PC SQL Developer 26.2 no tiene instalador: es una carpeta. El programa está en C:\Oracle\sqldeveloper-26.2.0.186.2220-x64\sqldeveloper\sqldeveloper.exe. Para abrirlo:

1. Abre el Explorador de archivos y entra en esa carpeta.

2. Haz doble clic en sqldeveloper.exe. La primera vez tarda (30 a 60 segundos) porque prepara su configuración.

3. Si pregunta si quieres importar preferencias de otra versión, responde No.

4. Aparece la «Página de bienvenida». A la izquierda está el panel Conexiones.

Truco: clic derecho sobre sqldeveloper.exe → Enviar a → Escritorio (crear acceso directo), para no buscar la carpeta cada vez.

Comprobar primero que Oracle está encendido

Si Oracle está apagado, SQL Developer no puede hacer nada. Para comprobarlo, abre Símbolo del sistema y escribe:

lsnrctl status

En la respuesta debe aparecer una línea con Service "freepdb1". Si dice «TNS: no listener», abre Servicios de Windows y arranca OracleOraDB23Home1TNSListener y OracleServiceFREE (o reinicia el PC). La comprobación automática E02 del instalador hace exactamente esta revisión.

Crear la conexión ECOACCESS_BD

Una conexión es una «tarjeta de visita» guardada: dice a qué servidor ir y con qué usuario entrar. Se crea una vez y luego basta con hacer doble clic en ella.

PasoQué hacerPor qué
1En el panel Conexiones, pulsa el botón verde + (Nueva conexión).Abre el formulario de conexión.
2Name (nombre): EcoAccess local - ECOACCESS_BD.Es solo una etiqueta para reconocerla. Pon «local» para no confundirla con la nube.
3Tipo de base de datos: Oracle.SQL Developer también habla con otros motores.
4Usuario: ECOACCESS_BD.El dueño del modelo.
5Contraseña: escríbela tú. Puedes dejar sin marcar «Guardar contraseña» para que la pida cada vez.No queda escrita en ningún archivo del proyecto.
6Tipo de conexión: Básico.No necesita wallet; eso es solo para la nube.
7Nombre del host: localhost.El servidor es el mismo PC.
8Puerto: 1521.El puerto donde escucha el listener.
9Marca Nombre del servicio (no SID) y escribe FREEPDB1.Con SID FREE entrarías al contenedor raíz, donde NO están las tablas del proyecto.
10Pulsa Probar. Abajo a la izquierda debe decir Estado: Correcto.Confirma usuario, contraseña y ruta.

Repite lo mismo para ECOACCESS_PRACTICAS (los ejercicios de clase) y ECOACCESS_BD_LECTOR (para comprobar lo que ve Power BI). Usa nombres distintos, por ejemplo EcoAccess local - PRACTICAS y EcoAccess local - LECTOR.

Si existe una conexión llamada «EcoAccess Cloud auditoria», esa apunta a Oracle Cloud y usa wallet. No la uses para este proyecto académico local: son contextos distintos y la nube no se modifica.

Ejecutar SQL: Ctrl+Enter frente a F5

En la hoja de trabajo escribe una consulta, por ejemplo:

SELECT codigo, descripcion FROM rol ORDER BY id_rol;
TeclaNombre en SQL DeveloperQué haceCuándo usarla
Ctrl+Enter (o el triángulo verde)Ejecutar sentenciaEjecuta SOLO la sentencia donde está el cursor y muestra el resultado en una cuadrícula (pestaña «Resultado de la consulta»).Para una consulta suelta que quieres mirar como tabla.
F5 (icono de hoja con triángulo)Ejecutar scriptEjecuta TODO el contenido de la hoja, sentencia por sentencia, como lo haría SQL*Plus, y muestra texto en la pestaña «Salida de script». Respeta PROMPT, SET SERVEROUTPUT ON y @archivo.Para correr un archivo completo: las pruebas, las consultas de exposición, un bloque PL/SQL con DBMS_OUTPUT.

Para ver los mensajes de DBMS_OUTPUT.PUT_LINE con F5, la primera línea del script debe ser SET SERVEROUTPUT ON. Los scripts del proyecto ya la traen.

COMMIT y ROLLBACK. Cuando haces un INSERT, UPDATE o DELETE en SQL Developer, el cambio queda pendiente: solo tu sesión lo ve. COMMIT (o F11) lo confirma para todos; ROLLBACK (o F12) lo deshace. El archivo de pruebas 12_pruebas.sql termina con ROLLBACK a propósito: prueba todo y no deja basura.

Diez consultas para practicar en la hoja de trabajo

Escríbelas una por una y ejecuta cada una con Ctrl+Enter. Todas leen datos sintéticos.

-- 1. ¿Cuántas filas tiene cada tabla importante?
SELECT COUNT(*) FROM deposito;            -- 105
SELECT COUNT(*) FROM consulta_vision;     -- 187 (fotos analizadas; NO son depósitos)

-- 2. Depósitos por estado (0 = pendiente, 1 = verificado, 2 = rechazado)
SELECT estado_verificacion, COUNT(*) FROM deposito GROUP BY estado_verificacion ORDER BY 1;

-- 3. Las canecas y su color
SELECT nombre, categoria, estado FROM contenedor ORDER BY nombre;

-- 4. JOIN: material de cada depósito verificado
SELECT d.id_deposito, m.codigo AS material
FROM deposito d JOIN material m ON m.id_material = d.id_material_declarado
WHERE d.estado_verificacion = 1;

-- 5. HAVING: materiales con más de 5 verificados
SELECT m.codigo, COUNT(*) AS verificados
FROM deposito d JOIN material m ON m.id_material = d.id_material_declarado
WHERE d.estado_verificacion = 1
GROUP BY m.codigo HAVING COUNT(*) > 5 ORDER BY 2 DESC;

Si un nombre de columna de este ejemplo no coincide, mira la pestaña Columnas de la tabla: el diccionario de fichas (03_DICCIONARIO_DE_DATOS) tiene los 173 nombres exactos. Resultados reales de este PC: 105 depósitos, 187 fotos, estados 0→17, 1→76, 2→12, y en la consulta 5: PAPEL 10, LATA_ALUMINIO 9, CARTON 8, TETRAPAK 7, PET 6, VIDRIO 6. Las 22 consultas completas y comentadas están en 13_consultas_exposicion.sql y en el Manual de sustentación (13_SUSTENTACION).

Errores frecuentes y qué significan

ErrorQué quiere decirQué hacer
ORA-12541: no listenerNadie atiende en el puerto 1521.Arrancar el servicio del listener (lsnrctl start) o reiniciar Oracle.
ORA-12514: listener does not currently know of serviceEl nombre del servicio está mal escrito o la PDB está cerrada.Usar FREEPDB1 como nombre del servicio, no como SID. Si persiste, como SYSDBA: ALTER PLUGGABLE DATABASE FREEPDB1 OPEN;
ORA-01017: invalid username/passwordUsuario o contraseña incorrectos… o la variable TNS_ADMIN apunta a la wallet de la nube.Revisar mayúsculas de la contraseña. En este PC pasó con TNS_ADMIN: el instalador la fija a la configuración local.
ORA-28000: the account is lockedDemasiados intentos fallidos.Como SYSTEM: ALTER USER ECOACCESS_BD ACCOUNT UNLOCK;
ORA-00942: table or view does not existLa tabla no existe o tu usuario no tiene permiso.¿Estás en la conexión correcta? Con LECTOR es lo esperado para las tablas.
ORA-00001: unique constraint violatedIntentaste duplicar un valor único (por ejemplo, una segunda orden vigente en la misma caneca).Es una regla del negocio funcionando (prueba P084).
ORA-02291: integrity constraint violated - parent key not foundUna FK apunta a un padre que no existe.Insertar primero el padre.
ORA-02290: check constraint violatedUn valor rompe un CHECK (por ejemplo, estado 7).Usar un valor permitido; el anexo del diccionario trae las 81 condiciones.
ORA-201xxError de negocio lanzado por un trigger o paquete con RAISE_APPLICATION_ERROR.Leer el mensaje: explica la regla. La guía de SQL y PL/SQL y la guía de triggers línea por línea los listan.
SP2-0310SQL*Plus no pudo abrir un archivo.Ruta corta y sin tildes.

Lo que esta guía no afirma

Las instrucciones de esta guía corresponden a la configuración verificada por consola el 11/11/2026: conexiones a localhost:1521/FREEPDB1 de las tres cuentas (comprobación E04), 153/153 pruebas, 0 objetos inválidos. Todavía no incluye capturas de la hoja de trabajo de SQL Developer: tomarlas requiere escribir la contraseña de la conexión en la ventana del programa. Los pasos de la interfaz siguen la versión 26.2 instalada en el PC; si un botón tiene otro nombre en tu idioma, la función es la misma.
