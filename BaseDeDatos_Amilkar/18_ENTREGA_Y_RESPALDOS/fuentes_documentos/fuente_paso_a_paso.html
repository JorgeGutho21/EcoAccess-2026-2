Antes de empezar: qué tienes y qué está comprobado

Esta carpeta contiene el proyecto completo de Base de Datos de EcoAccess:

  • el esquema Oracle con sus pruebas;
  • las prácticas de clase;
  • la conexión desde C#;
  • el tablero de Power BI;
  • el informe final y la guía de estudio.

Todo se instaló y se probó en este mismo PC, en Oracle AI Database 26ai Free (localhost:1521/FREEPDB1):

  • se borró el esquema académico y se volvió a crear desde cero;
  • luego se ejecutaron todas las comprobaciones.

Este es el resultado real de esa ejecución:

{{MD:16_EVIDENCIAS_Y_PRUEBAS/RESUMEN_ULTIMA_EJECUCION.md}}

Qué falta y no se presenta como hecho:

  • mirar en pantalla los visuales de Power BI (el modelo y sus cifras sí están comprobados);
  • guardar el diagrama .dmd de Data Modeler (son 5 clics, capítulo 6);
  • elegir la rama de Git para subir el trabajo.

Instalar y probar todo con un solo comando

  1. Enciende Oracle si el PC estaba apagado. Normalmente arranca solo con Windows. Si no:
    • presiona Win + R, escribe services.msc, busca OracleServiceFREE y pulsa «Iniciar»;
    • haz lo mismo con OracleOraDB23Home1TNSListener.
  2. Abre la carpeta del proyecto en el Explorador de archivos. Escribe pwsh en la barra de direcciones y presiona Enter; se abre PowerShell justo en esa carpeta.
  3. Ejecuta: 
    pwsh -File .\INSTALAR_Y_PROBAR.ps1 -Reinstalar
    Te pedirá escribir BORRAR_ECOACCESS_BD. Esa confirmación solo afecta al esquema académico de prueba (datos sintéticos): nunca toca P3, la nube, HR ni otros esquemas.
  4. Espera unos 4 minutos. Verás líneas en verde (PASA) o en rojo (FALLA). Al final debe decir «28 de 28 comprobaciones PASAN».
  5. Abre el resumen 16_EVIDENCIAS_Y_PRUEBAS\RESUMEN_ULTIMA_EJECUCION.md. Las salidas completas, sin contraseñas, están en 16_EVIDENCIAS_Y_PRUEBAS\salidas\ultima_ejecucion\.

¿Y las contraseñas?

El instalador nunca escribe una contraseña en los scripts ni en los resultados. La busca en este orden:

  1. la variable de entorno ECOACCESS_BD_CLAVE (y sus equivalentes para las otras cuentas);
  2. el archivo _LOCAL_NO_PUBLICAR\credenciales_locales.env, que existe solo en tu PC;
  3. si no la encuentra, te la pide en pantalla sin mostrarla.

No entregues ni subas a Git la carpeta _LOCAL_NO_PUBLICAR.

Ver el proyecto en SQL Developer

  1. Abre SQL Developer y crea una conexión con el + verde:
    • Nombre: EcoAccess BD;
    • Usuario: ECOACCESS_BD;
    • Host: localhost, Puerto: 1521;
    • Nombre del servicio: FREEPDB1.
    Pulsa Probar, luego Guardar y luego Conectar.
  2. En el panel izquierdo despliega Tablas. Al hacer clic en DEPOSITO:
    • la pestaña Columnas muestra el comentario del diccionario de cada columna;
    • la pestaña Disparadores muestra los triggers.
  3. Usa Archivo → Abrir para abrir 04_SCRIPTS_ORACLE\13_consultas_exposicion.sql. Pon el cursor en una consulta y pulsa Ctrl+Enter; para el archivo completo, F5.
  4. Para la guía, abre 08_CONSULTAS_Y_EJERCICIOS\banco_ejercicios_BD.sql: cada ejercicio se puede ejecutar por separado.

Guardar el diagrama editable (.dmd) en Data Modeler

Este paso hay que hacerlo con el mouse, porque Data Modeler no se puede automatizar. Toma unos 2 minutos:

  1. En SQL Developer: Archivo → Data Modeler → Importar → Diccionario de datos.
  2. Elige la conexión EcoAccess BD y pulsa Siguiente. Marca el esquema ECOACCESS_BD y pulsa Siguiente.
  3. Marca las 19 tablas y pulsa Siguiente → Terminar.
  4. Si las líneas del diagrama se cruzan: clic derecho en el fondo → Diseño automático.
  5. Archivo → Data Modeler → Guardar como → 02_MODELOS_DE_DATOS\05_DATA_MODELER_EDITABLE\EcoAccess_BD.dmd. Entrega el .dmd junto con la carpeta del mismo nombre que se crea al lado.

Mientras tanto, 02_MODELOS_DE_DATOS ya tiene el MER y el modelo relacional por módulo en PNG, SVG y PDF, generados desde las tablas reales.

Abrir el tablero de Power BI

  1. Si moviste la carpeta del proyecto, ejecuta primero pwsh -File .\INSTALAR_Y_PROBAR.ps1 -SinEjercicios -SinCSharp. Así se actualizan los CSV y la ruta que usa el tablero.
  2. Abre 09_POWER_BI\PROYECTO_PBIP\EcoAccess_BD\EcoAccess_BD.pbip con Power BI Desktop.
  3. Pulsa Inicio → Actualizar. Las tarjetas de Inicio deben mostrar:
    • 187 fotos consultadas;
    • 105 depósitos registrados;
    • 76 verificados;
    • 675 EcoPuntos netos.
  4. Recorre las 5 páginas con los botones verdes: Operación, Ranking y pesos, EcoPuntos y auditoría, y Galería de roles.
  5. Archivo → Guardar como → EcoAccess_BD.pbix, si el profesor lo pide en ese formato.

El modelo ya está comprobado en este PC: carga, se actualiza, sus 15 medidas dan lo mismo que Oracle y los 50 visuales usan campos que existen. La evidencia está en 16_EVIDENCIAS_Y_PRUEBAS\salidas\powerbi_modelo_dax.txt. Lo único que no se pudo hacer fue mirar los visuales dibujados en pantalla.

La parte de C# (Visual Studio)

  1. Abre 10_CSHARP_VISUAL_STUDIO/SOLUCION_CSHARP\EcoAccessBD.sln en Visual Studio.
  2. Las contraseñas no van en el código. Antes de ejecutar, define las variables de entorno PRACTICAS_USUARIO, PRACTICAS_CLAVE, LECTOR_USUARIO y LECTOR_CLAVE, desde la terminal o en las propiedades de depuración del proyecto.
  3. Ejecuta EcoAccessBD.Consola: debe terminar con «TODO PASA».
  4. Ejecuta EmpleadosCrud.WinForms: tiene los botones Consultar, Insertar y Actualizar, y no tiene Eliminar, como pide la tarea.
  5. Si la compilación falla por una ruta demasiado larga, copia la carpeta 10_CSHARP_VISUAL_STUDIO/SOLUCION_CSHARP a C:\ecs y ábrela desde allí. El instalador hace eso automáticamente.

El día de la sustentación

  1. 15 minutos antes, ejecuta pwsh -File .\INSTALAR_Y_PROBAR.ps1 -SinEjercicios -SinCSharp y comprueba que todo salga en verde.
  2. Ten abiertos tres programas:
    • SQL Developer, con 13_consultas_exposicion.sql;
    • Power BI, en la página de Inicio;
    • el informe PDF.
  3. Sigue el guion de 13_SUSTENTACION\CHECKLIST_SUSTENTACION.md:
    • el problema;
    • el MER y el modelo relacional;
    • una columna del diccionario;
    • el trigger 2 (ORA-20101) y el trigger 3 (auditoría :OLD/:NEW);
    • la consulta Q01, Power BI y la práctica del precio.
  4. Si te preguntan «¿cómo sabes que funciona?», muestra 16_EVIDENCIAS_Y_PRUEBAS\RESUMEN_ULTIMA_EJECUCION.md y 04_SCRIPTS_ORACLE\DDL_FINAL_EXTRAIDO.sql.
